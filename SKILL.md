# Seasea Brand Skill (Global)

Author and revise Seasea.cc-branded artifacts with the canonical brand system applied — positioning, voice, visual identity, bright-blue gradient discipline, and anti-default governance — so every output reads like a $250k-engagement consulting deliverable from the AI-era Accenture/Deloitte equivalent.

## Strategic Frame

**Seasea is the AI-native growth operating system.** It is the AI-era successor to McKinsey / Accenture / Deloitte / BCG: the firm that codifies expert judgment into ontology, permission graph, workflow DAGs, and execution journals — not a SaaS dashboard, not a chatbot, not a prompt library.

The brand must communicate **earned intelligence, decision-grade rigor, and quiet authority** — never hype, never rainbow-AI playfulness, never consumer warmth.

## When to Use

- User asks to design or write any Seasea.cc surface: website, landing page, pitch deck, sales deck, RFP response, case study, social post, narration script, GPT Image 2 prompt, client deliverable
- User asks to "apply Seasea brand", "make this look Seasea", "套用 Seasea 品牌", "Seasea consulting deliverable"
- A Seasea Group business unit needs a Seasea-master-brand artifact (parent-brand cooperation, group-level investor deck, group press)
- User asks for a Seasea homepage, agent OS landing page, or Intelligence OS visual

If the artifact is for **Musein.ai** use `musein-brand` instead. If for **ModelAPI.co** use `modelapi-brand` instead. Seasea-brand is the **parent / consulting-house master brand**.

### The Seasea Gradient (canonical)

```
Strategic Navy #1E3A8A  →  Electric Cobalt #0048FF  →  Lumen Sky #2BB8FF
        deep              decision-grade               insight-bright
```

Read this gradient as a **strategic narrative**: depth of judgment → decision moment → emergent insight. Never invert it. Never replace any stop with a non-blue color.

**Rules:**
- The Seasea gradient is the **only** decorative gradient. No magenta, no green, no orange in any gradient.
- Use the gradient sparingly: hero glow, headline underline, single CTA fill, single chart series, one accent line per layout. Never as the dominant page background.
- Insight Indigo + Boardroom White / Pure White are dominant; bright cobalt is the accent of intelligence — used like a highlighter, not like wallpaper.
- Gradient direction: 135° (top-left dark → bottom-right bright) is canonical; 90° horizontal is allowed; never radial-rainbow, never animated multi-hue.
- Functional colors (Verified Green / Audit Amber) are functional only — never decorative.

### Typography

| Level | Direction | Use |
| --- | --- | --- |
| Display / Editorial | **PP Editorial New** (italic for emphasis), Tiempos Headline, GT Sectra | Hero headlines, master-brand moments, big numbers in decks |
| UI / Body sans | **Geist** (preferred), Söhne, Neue Haas Grotesk | Product UI, sales decks, body copy |
| Data / Mono | **Geist Mono**, JetBrains Mono, IBM Plex Mono | Workflow node labels, code, data tables, audit metadata |

**Banned fonts** (per [`high-end-visual-design`](../high-end-visual-design/SKILL.md) defaults Seasea adopts): Inter, Roboto, Arial, Open Sans, Helvetica, system-ui without override, Calibri, Times New Roman.

**Rules:**
- Editorial serif italic on the **first key noun** of a hero headline is a Seasea signature ("The *intelligence* operating partner"). Use sparingly — once per hero.
- Title : subtitle ratio ≥ 2.5×. No decorative letter-spacing on body. No centered all-caps body.
- Display serif used only for brand moments (hero, section opener, big stat). Not for nav, buttons, captions.
- Numbers in decks: tabular figures, Geist Mono or Geist with `font-variant-numeric: tabular-nums`. Always tabular-aligned in tables.

### Layout

- 12-column grid, 1440px or 1920px reference; gutter ≥ 32px
- Whitespace ≥ 35% of any hero composition (premium = breathing room)
- One core insight per page / per slide / per fold
- Editorial alignment — left-aligned headlines, generous left margin (no centered hero text on landing pages)
- Footer source citation on data slides / data sections (Seasea is source-bound)
- Boardroom slide format 1920×1080, 5% top-left blank zone reserved (logo safe — never draw the logo inside generated images)
- `Privileged&Confidential` watermark in small light-gray bottom-right on every restricted slide

### Icons & Iconography

- **Phosphor Light**, **Remix Line**, or custom 1px line iconography only.
- Banned: Material Icons, FontAwesome solid, thick-stroked Lucide defaults, emoji, 3D glossy icons.
- Replace any "AI / sparkles / magic wand" icon with: a network node, a permission graph, an audit checkmark, an editorial dot, a layered card, or the Seasea gradient underline.

### Imagery

- Use abstract: ontology graphs, decision trees, layered card stacks, permission matrices, vector portrait silhouettes (line art, not photo), satellite ocean imagery (Seasea = sea + intelligence).
- Banned: stock-photo people in suits, handshake / coin / rocket / globe / lightbulb metaphors, AI brain illustrations, robot icons, chatbot speech bubbles, 3D character avatars, generative-art rainbow noise.
- If a person must appear, it is a **monochrome editorial portrait** (Insight Indigo duotone or pure black-and-white), never a smiling stock photo.

### Motion

- Eased cubic-bezier `(0.16, 1, 0.3, 1)` (premium overshoot) or `(0.4, 0, 0.2, 1)` (calm). No `ease-in-out` defaults, no linear.
- Hover states: 200–280ms. Page transitions: 400–600ms. Hero reveal: ≤ 1200ms.
- Subtle parallax on Seasea gradient (max 12px translate) only on hero — never on body sections.
- Banned: bouncy springs, glitchy AI text reveals, neon flicker, rainbow shifts, infinite background animation that distracts from copy.

## GPT Image 2 Preamble (for Seasea-branded image generation)

Every Seasea GPT Image 2 prompt must open with this canonical preamble:

```text
Create a 16:9 executive strategy slide image, 1920x1080, for Seasea — the AI-native growth operating system positioned as the AI-era equivalent of Accenture and Deloitte. Use a premium consulting visual standard: editorial information hierarchy, generous whitespace, dense but scannable strategic content, crisp vector-like ontology diagrams, refined typography, and zero consumer-app playfulness. Background: Boardroom White / soft off-white. Primary text: Graphite Black on Insight Indigo for hero passages. Accent: bright Electric Cobalt to Lumen Sky gradient (only blue stops, never multi-hue), used only for active decision paths, key emphasis, and intelligence highlights. In the upper-left corner, reserve a blank square equal to 5% of the total image width — keep this area identical to the background, with no border, no placeholder, no icon, no logo, no framing. Do not draw the Seasea logo. Add the exact text "Privileged&Confidential" in small light-gray type at the bottom-right corner.
```

After the preamble, every prompt must declare:

1. **Slide theme** — the page's strategic role and one-line hook
2. **Core content to show** — every factual element (named modules, numbers, ontology nodes) — never vague hype
3. **Visual direction** — composition, gradient placement, layout grammar, restated forbidden visuals (no stock-photo people, no rainbow, no robot/brain icon)

## Master-brand vs Sub-brand Co-Lock

When a Seasea sub-brand artifact (Musein, ModelAPI, Antifomo, Boids) needs Seasea co-branding:

- Seasea wordmark sits in the **footer** or top-right secondary slot — never replaces the sub-brand wordmark in the hero.
- Seasea blue gradient may **frame** the sub-brand (top edge, footer rule) but does not override the sub-brand's primary palette.
- Use the line: *"A Seasea Intelligence OS company"* / *"Part of the Seasea Group"* — never "by Seasea" (too modest), never "from the Seasea family" (too soft).
